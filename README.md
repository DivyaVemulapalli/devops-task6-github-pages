# DevOps Internship – Task 6

## Hosting a Static Website with GitHub Pages

### Objective

Create and host a personal portfolio website using HTML and CSS, and publish it online using GitHub Pages.

### Tools and Technologies

* HTML5
* CSS3
* Git and GitHub
* GitHub Pages
* Visual Studio Code

### Project Description

This project involved creating a responsive personal portfolio website to showcase my skills, DevOps projects, and professional profile.

The website was developed using HTML for structure and CSS for styling. GitHub Pages was used to publish the static website directly from the repository's `main` branch.

### Website Features

* Modern dark-themed design
* About Me section
* Technical skills section
* DevOps project cards
* Links to GitHub repositories
* LinkedIn profile link
* Responsive layout for different screen sizes

### Project Structure

```text
devops-task6-github-pages/
├── index.html
├── style.css
└── README.md
```

### Deployment Steps

1. Created a GitHub repository for the portfolio website.
2. Developed the website using HTML and CSS.
3. Uploaded `index.html` and `style.css` to the repository.
4. Committed the files to the `main` branch.
5. Opened the repository's Settings and selected Pages.
6. Configured GitHub Pages to deploy from the `main` branch and root folder.
7. Saved the settings and verified the deployment.
